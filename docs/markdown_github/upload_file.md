# Upload a file

Upload a file from your computer to Google Drive.

You must be signed in to your Google Account.

1.  Click **New**.

2.  Select **File upload**.

    A file selection window opens.

3.  Select the file, and then click **Open**.

4.  Open **Google Drive** on your mobile.

5.  Tap the **+** icon, and then tap **Upload**.

    A file selection screen opens.


The file appears in My Drive.
