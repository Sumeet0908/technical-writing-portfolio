# About sharing in Google Drive

Share your files and folders with others.

You can control who can open the files and folders you share.

-   Share the file or folder with specific people.
-   Choose what each person can do with it.
-   Change or remove a person's access at any time.

**Tip:** Share only with the people who need access.
