Access levels

Compare what each access level and general access option allows.

Access levels for people

Level Permission
Viewer Can open and view the file.
Commenter Can open, view, and add comments to the file.
Editor Can open, view, comment on, and edit the file.

General access

Option Description
Restricted Only the people you add can open the file.
Anyone with the link Anyone who has the link can open the file.
