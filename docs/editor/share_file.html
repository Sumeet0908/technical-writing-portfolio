Share a file

Share a file in Google Drive with another person.

You must own the file or have permission to share it.
Warning:
Back up your files before you continue.
Note:
You can share the file only if the owner allows editors to change permissions and share.
Tip:
Alternatively, click Copy link, and then send the link to the person.
  1. In Google Drive, right-click the file, and then select Share.
  2. In the sharing box, enter the name or email address of the person.
  3. Select the access level for the person.
    For available levels, see Access levels.
  4. Click Send.
The person receives an email with a link to the file.
