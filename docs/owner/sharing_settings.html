Change sharing settings

Control what editors, commenters, and viewers can do with the shared file.

You must be the owner of the file.
  1. In Google Drive, right click the file and select Share.
  2. Click the Settings icon.
    Setting page for the file opens.
  3. Check or uncheck the options that you want to change.
    • Allow editors to change permissions and share: Lets editors change access and share the file with others.
    • Editors: Lets editors download, copy, print, and access the file through Gemini.
    • Commenters and viewers: Lets commenters and viewers download, copy, print, and access the file through Gemini.
The new settings are applied to the file.
